## Как обновлять сайт
Пуш в GitHub → на сервере **cron каждую минуту** делает `git pull` в `/var/www/pricepy` (автодеплой). Ручной пуш локально: `git add -A && git commit && git push`.
Секреты сервера НЕ в git: `/var/www/pricepy/api/config.php` (в .gitignore), `leads.log`.
