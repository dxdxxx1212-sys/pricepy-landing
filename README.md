# Восток Прицеп — лендинг + приём заявок + мини-CRM

Один репозиторий, один сервер (`/var/www/pricepy`), автодеплой: cron раз в минуту делает
`git fetch && git reset --hard origin/main`. **Всё, что не в git, на сервере не живёт** — кроме
`api/config.php` (секрет), базы и вложений CRM в `/var/lib/pricepy-crm/` (вне веб-корня).

## Что где

| Путь | Что это | Домен |
|---|---|---|
| `index.html` | лендинг с квизом (HTML+CSS+JS в одном файле, без сборки) | восток-прицеп.рф, jefwipwero.online |
| `v2.html`, `v3.html` | варианты лендинга под поддомены | подбор.…, прицеп.… |
| `api/lead.php` | приём заявки: копия в `leads.log` (РФ, 152-ФЗ) → Telegram через воркер → запись в CRM | `/api/lead` на всех доменах лендинга |
| `worker/lead-worker.js` | Cloudflare Worker: доставка в Telegram (api.telegram.org с РФ-сервера закрыт). **Деплоится вручную** | — |
| `crm/` | панель для владельца и операторов (PHP + SQLite) | crm.восток-прицеп.рф |
| `*.sh` | скрипты первичной настройки сервера (nginx, HTTPS, каталоги) — запускаются один раз | — |
| `trailers-source.json` | исходные данные каталога | — |

## Как устроена CRM (`crm/`)

Страницы — плоский PHP без фреймворка: `index.php` (список лидов), `view.php` (карточка),
`hist.php` (поп-ап комментариев из списка), `users.php` (операторы, только владелец),
`login.php`/`logout.php`, `ping.php` (сигнал о новом лиде), `att.php` (отдача фото — только авторизованным).
CLI-скрипты: `mkowner.php` (создать пользователя), `import-log.php`, `import-tg.php` (исторические лиды).

Общий код подключается одной строкой `require __DIR__.'/lib.php'`; сама логика — в `crm/inc/`:

| Модуль | Содержимое |
|---|---|
| `config.php` | пути к базе/вложениям, версия схемы, адреса воркера и панели (переопределяются переменными окружения `CRM_DB`, `CRM_UPLOAD`, `CRM_WORKER`, `CRM_BASE`) |
| `util.php` | `h()`, `crm_now()`, даты, разбор телефона (`crm_phone_norm` — единственное место), склонения |
| `dict.php` | справочники: статусы сделки, каналы связи, канал из квиза, иконки, плашки |
| `db.php` | подключение, схема, миграции (гоняются только когда `PRAGMA user_version` < `CRM_SCHEMA_VERSION`) |
| `auth.php` | сессия, вход, роли, CSRF, антибрутфорс |
| `comments.php` | комментарии и вложения (фото), правка/удаление — только владелец |
| `leads.php` | действия над лидом (`crm_process_lead_action`), приём (`crm_insert_lead`), авто-подача по долям, массовая передача, удаление |
| `tg.php` | уведомления операторам в личный Telegram через воркер |
| `ui.php` | шапка/подвал страницы, плашки, скрытые поля форм |

Стили и скрипты панели — `crm/assets/crm.css`, `crm/assets/crm.js` (кэш сбрасывается через `?v=mtime`).

### Инварианты (не ломать)

- База и вложения — **вне веб-корня и вне git**: `/var/lib/pricepy-crm/leads.sqlite`, `…/uploads/`. Фото отдаёт только `att.php` за авторизацией (в них ПДн клиентов).
- Оператор видит только назначенные ему лиды — ограничение серверное (`crm_lead_scope_sql`, `crm_can_see_lead`), не только в интерфейсе.
- Назначение, удаление лида, правка/удаление комментариев, страница операторов — только владелец, проверка на сервере.
- Все изменения — POST с CSRF, после обработки — редирект (PRG), чтобы F5 не повторял действие.
- Телефон хранится как есть в `contact`, ключ для дедупа/поиска — `phone_norm` = `7XXXXXXXXXX`.
- Схема меняется только через `crm_migrate()` + увеличение `CRM_SCHEMA_VERSION`.
- Приём заявки (`api/lead.php`) подключает `crm/lib.php` **в самом конце и внутри try/catch**: любая ошибка CRM не может сорвать доставку заявки в Telegram. Не переносить require наверх.
- На доменах лендинга PHP исполняется только через `location = /api/lead`; любой другой `.php` nginx должен отдавать 403 (см. `harden-php-static.sh`).

## Локальный стенд CRM

Панель запускается встроенным сервером PHP на копии/пустой базе — база создаётся сама по схеме:

```bash
CRM_DB=/tmp/crm-test.sqlite CRM_UPLOAD=/tmp/crm-uploads CRM_WORKER=http://127.0.0.1:9/ php -S 127.0.0.1:8765 -t crm
```

Пользователя создать `php crm/mkowner.php` с теми же переменными окружения. Cookie сессии помечена `Secure`,
поэтому по http браузер её не пришлёт — для ручной проверки удобнее `curl -b "PHPSESSID=…"`.

## Настройка сервера с нуля

`deploy.sh` (nginx + PHP + HTTPS для основного домена) → `domain-vostok.sh` (восток-прицеп.рф) →
`subdomain-crm.sh` (CRM, база, бэкап в cron) → `subdomain-podbor.sh` / `subdomain-pricep.sh` (варианты лендинга).
Скрипты запускаются по raw-ссылке с SHA коммита (github.io кэширует старые версии).
Секрет воркера: `api/config.php` (`$LEAD_SECRET`) и та же переменная в Cloudflare.
