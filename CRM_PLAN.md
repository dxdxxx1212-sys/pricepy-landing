# CRM «Восток Прицеп» — план и статус

Мини-CRM для обработки лидов с лендингов: операторы и владелец видят заявки, трекают
статусы (дозвон/не дозвон), мессенджер, комментарии, этапы воронки, перезвоны.

**Статус на 2026-09-06:** Фаза 1 (MVP) — **код написан, отревьюжен 3 агентами (2 раунда),
укреплён по всем P0/P1, деплоится.** Второй раунд ревью закрыл: утечку логов ПДн из веб-корня,
лимит размера тела + анти-флуд на `/api/lead`, захват UTM/gclid/yclid на лендинге, потерю
моделей из корзины (`items`), единый минимум пароля, `Secure`-куку, ежедневный бэкап базы.

---

## Решение (утверждено «на берегу»)
Выбран **свой лёгкий CRM на нашем сервере** (не готовый Bitrix24/amoCRM, не таблица).
Причины: лиды уже идут через наш `api/lead.php`; ПДн держим в РФ; требования простые.

## Архитектура
- **База:** SQLite по пути `/var/lib/pricepy-crm/leads.sqlite` — **вне веб-корня** (нельзя
  скачать через браузер), не в git (переживает автодеплой `git reset --hard`, как `leads.log`).
- **Приём лида:** `api/lead.php` пишет лид в базу **ПОСЛЕ** доставки в Telegram, в `try/catch`.
  Порядок: `leads.log → Telegram (Worker) → БД → ответ`. Сбой БД логируется в `leads-errors.log`
  и **не влияет** на доставку лида. Пока папки БД нет — запись просто не удаётся, лид доходит.
- **Панель:** поддомен `crm.восток-прицеп.рф`, root `/var/www/pricepy/crm`, PHP-FPM, HTTPS.
  Серверный рендер (PHP+HTML), вход по логину/паролю (bcrypt + сессии + CSRF).
- **Роли:** `owner` (владелец — всё + операторы + KPI), `operator` (работа с лидами).

## Модель данных (SQLite, схема в `crm/lib.php` → `crm_init_schema`)
- **leads:** id, created_at, source, name, contact, channel, use_, capacity, type, budget,
  timing, utm_source/medium/campaign/content/term, ip, ua, raw(json), **status**,
  **call_status**, assignee_id, next_action_at, sale_amount, model, reject_reason, updated_at.
- **users:** id, login, pass_hash, name, role, active, created_at.
- **comments:** id, lead_id, user_id, body, created_at.
- **events** (история действий): id, lead_id, user_id, type, detail, created_at.
- **login_fails** (антибрутфорс): ip, ts.

## Воронка (этапы) и статус звонка
- **status:** new (Новый) → work (В работе) → reached (Дозвонились) → qualified
  (Квалифицирован) → deal (Оформление) → won (Продажа) / lost (Отказ).
- **call_status:** '' / answered (Дозвон) / noanswer (Не дозвон) / callback (Перезвонить).

## Файлы (в репозитории `pricepy-landing`)
| Файл | Назначение |
|---|---|
| `crm/lib.php` | Ядро: PDO/SQLite, схема, авторизация (bcrypt/сессии/CSRF), троттлинг логина, справочники статусов, вёрстка панели (`crm_head`/`crm_foot`), таймзона Europe/Moscow. |
| `crm/login.php` / `logout.php` | Вход/выход (с антибрутфорсом). |
| `crm/mkowner.php` | **CLI-скрипт** создания пользователя (пароль вводится скрыто, `php crm/mkowner.php`). Через веб — 403. |
| `crm/index.php` | Список лидов: фильтры (статус/источник/оператор/поиск/«перезвонить сегодня»), KPI. |
| `crm/view.php` | Карточка лида: этапы, звонок, оператор, перезвон (datetime-local), модель/сумма/причина, комментарии, история. PRG. |
| `crm/users.php` | Управление операторами (owner-only), защита последнего владельца. |
| `api/lead.php` | Дополнен записью лида в БД (после доставки в TG, в try/catch). |
| `subdomain-crm.sh` | Скрипт на сервере: nginx+HTTPS для crm.*, папка БД вне корня, deny-правила, заголовки безопасности. |

## Безопасность (что учтено)
- bcrypt (`password_hash`/`verify`), сессии `HttpOnly`+`Secure`+`SameSite=Strict`, `session_regenerate_id` при входе.
- Все SQL — prepared statements (нет инъекций). Весь вывод через `h()`/`htmlspecialchars` (нет XSS). CSRF-токен + `hash_equals` на всех POST.
- База вне веб-корня; nginx deny для `.sqlite/-wal/-shm/.log/.sh` + скрытых, deny выше `.php`, `= /lib.php`/`= /mkowner.php`.
- Заголовки `X-Frame-Options: DENY`, `X-Content-Type-Options: nosniff`, `HSTS`.
- Антибрутфорс логина: ≤10 попыток / 15 мин с IP.
- Создание владельца только из CLI (нет веб-seed, закрыта дыра «первого входа»).

## Как задеплоить (по шагам)
1. **Пуш в main** (после «деплой» пользователя) → автодеплой подтянет `crm/*`, новый `lead.php`.
   Приём заявок не ломается (защита + try/catch). Сразу проверить curl'ом `/api/lead`.
2. **DNS (sprinthost):** A-запись `crm → 45.150.39.174`.
3. **На сервере:** `curl -fsSL https://dxdxxx1212-sys.github.io/pricepy-landing/subdomain-crm.sh | bash`
4. **Создать владельца:** `php /var/www/pricepy/crm/mkowner.php` (пароль скрыт).
5. Зайти на `https://crm.восток-прицеп.рф`.
